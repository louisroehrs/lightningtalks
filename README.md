# lightningtalks

This is the lightning talks signboard.  It is meant to run on a machine connected to the signboard and extended displays.

The external display/sign board browse to http://localhost:9100/agenda.html.

On the laptop display, browse to http://localhost:9100/editor.html.

Clone this directory.

cd lightningtalks

./start.sh

This will open two windows.  The editor window and the display window.

Click the page on the editor window you wish to display and wait no more than 5 seconds.

You can edit the display in the editor window, drag and drop the order of lists, and click update.

Click a page will update the system with the current form entries.

Enjoy!
